GITHUB PAGES SETUP
1. Extract this ZIP.
2. Upload index.html, style.css and script.js (if present), plus the complete assets folder to the ROOT of your ward34-info repository.
3. Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Wait for the Pages deployment to finish.
5. Website: https://rzadanyal-byte.github.io/ward34-info/
6. The included QR points to that URL.
